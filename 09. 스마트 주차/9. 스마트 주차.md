# 스마트 주차 
## 스마트 주차 보조 시스템 구현
본 프로젝트는 초음파 거리 센서(SR04), 4-Digit FND(HT16K33), 조도 센서, 푸시 스위치를 결합하여 “자동차의 후진 상황에서 주변 장애물과의 거리를 직관적으로 표시하는 HUD(Head-Up Display)” 형태의 스마트 주차 보조 시스템을 구현하는 것을 목표로 합니다.

단순히 `거리 값만 숫자로 보여주는 장치`가 아니라, 실제 차량 보조 시스템처럼

- 언제 표시를 활성화할지(기어 상태)
- 어떻게 보기 좋게 표시할지(표시 형식/애니메이션)
- 어두운 환경에서 눈부심을 줄이는 방법(자동 디밍)

을 한 흐름으로 설계하는 것이 핵심입니다.

예를 들어,

- 주차 시 운전자는 “현재 기어가 후진인지”에 따라 거리가 표시되는지가 달라져야 한다고 기대합니다.
- 야간에는 밝은 디스플레이가 눈부시기 때문에 조도에 따라 자동으로 밝기가 낮아져야 합니다.
- 주행(Drive) 상태에서는 거리 표시보다 “시스템이 정상 동작 중임”을 직관적으로 알 수 있는 간단한 애니메이션이 더 유용할 수 있습니다.

따라서 본 프로젝트는 R/N/D 상태 전환 + 거리 측정 + 자동 디밍 + 애니메이션을 결합하여, `교육용이지만 실제 동작 원리를 잘 보여주는` 실습 예제로 구성합니다.

## 구성 요소별 역할
### 초음파 센서
물체까지의 거리를 음파의 왕복 시간을 통해 측정합니다.
- 측정 거리 범위: 약 2 cm ~ 400 cm
- 후진(R) 상태일 때 거리값을 실시간으로 측정하여 FND에 m 단위 소수점 2자리(예: 0.45 m) 로 표시합니다.

### FND 
거리값 및 시스템 상태를 표시하는 시각적 인터페이스 역할을 합니다. 본 프로젝트에서 사용하는 4-Digit FND는 HT16K33 드라이버가 포함되어 있어, MCU는 I²C 통신(SDA/SCL) 으로 표시를 제어합니다.
- R 상태: 초음파 센서로 측정된 거리값을 왼쪽 1칸 공백 + m 단위 소수 2자리로 표시합니다.
- N 상태: ---- 표기 (중립 상태)
- D 상태: 네 자리 전체를 하나의 사각형으로 보고, 외곽 LED가 한 부분씩 꺼졌다 켜지는 애니메이션을 통해 “주행 준비 상태”를 표현합니다.

### 조도 센서
주변 밝기에 따라 FND의 밝기를 자동으로 조정합니다.
- 밝을수록 더 밝게, 어두울수록 더 어둡게 (정비례 디밍)
- 10단계 세분화로 자연스러운 변화를 구현하였으며, 내부적으로 EMA(지수 이동 평균) 필터를 적용해 조도 변화에 의한 깜빡임을 최소화했습니다.

### 푸시 스위치
자동차의 기어 상태를 모사합니다.
| 스위치 | 기능 | 설명 |
| :--- | :--- | :--- |
| D | Drive | 주행 대기 / 사각형 외곽 애니메이션 |
| N | Neutral | 중립 상태(`----`) 표시 |
| R | Reverse | 거리 측정 및 거리 표시 활성화 |

## 동작 구조
1. N(중립) 상태
    - 4-Digit FND에 ---- 출력
    - 센서 대기 상태 유지
2. D(주행) 상태
    - 4개의 FND를 하나의 사각형으로 보고 외곽 LED(A,B,C,D,E,F)가 모두 켜진 상태에서 둘레를 따라 한 부분씩 OFF 되는 순차 애니메이션이 반복 실행됩니다.
3. R(후진) 상태
    - 초음파 센서를 이용해 실시간 거리 측정
    - 유효 거리일 경우 m 단위 소수 2자리로 표시
    - 감지 실패 시 ---- 표시
    - 주변 조도에 따라 자동으로 밝기 보정

## 스마트 주차 코드 작성

```cpp
#include <Wire.h>
#include <math.h>

#define DEBUG_ULTRA 0
#define DP_IN_SEGMENT true
#define HT16K33_ADDR 0x70

const int PIN_TRIG = 8;
const int PIN_ECHO = 9;
const int PIN_LIGHT = A0;
const int PIN_D = 4;
const int PIN_N = 5;
const int PIN_R = 6;

const uint8_t SEG_A=1<<0, SEG_B=1<<1, SEG_C=1<<2, SEG_D=1<<3, SEG_E=1<<4, SEG_F=1<<5, SEG_G=1<<6;

uint8_t digitMap[10] = {
  0b00111111,
  0b00000110,
  0b01011011,
  0b01001111,
  0b01100110,
  0b01101101,
  0b01111101,
  0b00000111,
  0b01111111,
  0b01101111 
};
const uint8_t SEG_DASH  = 0b01000000;
const uint8_t SEG_BLANK = 0x00;
const uint8_t POS_ADDR[4] = {0x00, 0x02, 0x04, 0x06};

static inline void ht_cmd(uint8_t c){ Wire.beginTransmission(HT16K33_ADDR); Wire.write(c); Wire.endTransmission(); }
void ht_init(){
  Wire.begin();
  ht_cmd(0x21);
  ht_cmd(0x81);
  ht_cmd(0xE0 | 0x0F);
  Wire.beginTransmission(HT16K33_ADDR);
  Wire.write(0x00); for(int i=0;i<16;i++) Wire.write(0x00);
  Wire.endTransmission();
}

void ht_brightness(uint8_t lvl){ if(lvl>15) lvl=15; ht_cmd(0xE0 | lvl); }

void ht_write_digit(uint8_t idx, uint8_t seg, bool dp){
  if(idx>3) return;
  uint8_t even = POS_ADDR[idx];
  uint8_t odd  = even + 1;

  uint8_t seg_out = seg;
  uint8_t icon_out = 0x00;

  if (DP_IN_SEGMENT) {
    if (dp) seg_out |= 0x80;
  } else {
    if (dp) icon_out |= 0x01;
  }

  Wire.beginTransmission(HT16K33_ADDR);
  Wire.write(even);
  Wire.write(seg_out);
  Wire.write(icon_out);
  Wire.endTransmission();
}

void disp_dashes(){ for(int i=0;i<4;i++) ht_write_digit(i, SEG_DASH, false); }

void disp_m2_shifted(float m){
  if (m < 0.0f) { disp_dashes(); return; }
  if (m > 9.99f) m = 9.99f;
  int hundred = (int)(m*100.0f + 0.5f);
  int iPart = hundred/100;
  int d1 = (hundred/10)%10;
  int d2 = hundred%10;

  ht_write_digit(0, SEG_BLANK, false);
  ht_write_digit(1, digitMap[iPart], true);
  ht_write_digit(2, digitMap[d1], false);
  ht_write_digit(3, digitMap[d2], false);
}

static inline void ultra_trigger(){
  digitalWrite(PIN_TRIG, LOW);  delayMicroseconds(3);
  digitalWrite(PIN_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
}
unsigned long read_echo_us(){
  ultra_trigger();
  return pulseIn(PIN_ECHO, HIGH, 50000UL);
}

float read_distance_m(){
  static unsigned long lastTrig = 0;
  unsigned long now = millis();
  if (now - lastTrig < 60) delay(60 - (now - lastTrig));
  lastTrig = millis();

  unsigned long t[3];
  for(int i=0;i<3;i++){ t[i]=read_echo_us(); delay(5); }
  if(t[0]>t[1]){ auto x=t[0]; t[0]=t[1]; t[1]=x; }
  if(t[1]>t[2]){ auto x=t[1]; t[1]=t[2]; t[2]=x; }
  if(t[0]>t[1]){ auto x=t[0]; t[0]=t[1]; t[1]=x; }

  unsigned long us = t[1];
  if(us==0) return -1.0f;

  float cm = (us * 0.0343f) * 0.5f;
  return cm / 100.0f;
}

const uint8_t BR_MAP[10] = {1,2,3,4,5,7,9,11,13,15};
float light_ema = 0.0f;
const float LIGHT_ALPHA = 0.20f;

uint8_t light_to_brightness_10step(uint16_t adc){
  light_ema = (1.0f - LIGHT_ALPHA)*light_ema + LIGHT_ALPHA*(float)adc;
  int idx = (int)(light_ema / 102.4f);
  if (idx < 0) idx = 0;
  if (idx > 9) idx = 9;
  return BR_MAP[idx];
}

enum Gear { GEAR_D, GEAR_N, GEAR_R };
Gear currentGear = GEAR_N;

bool pressed_stable(int pin){
  if (digitalRead(pin)==HIGH){ delay(20); return (digitalRead(pin)==HIGH); }
  return false;
}

void update_gear_latch(){
  bool rNow = pressed_stable(PIN_R);
  bool dNow = pressed_stable(PIN_D);
  bool nNow = pressed_stable(PIN_N);
  if(rNow){ currentGear=GEAR_R; return; }
  if(dNow){ currentGear=GEAR_D; return; }
  if(nNow){ currentGear=GEAR_N; return; }  
}

static inline uint8_t segs(bool A,bool B,bool C,bool D,bool E,bool F,bool G=false){
  uint8_t m=0;
  if(A) m|=SEG_A; if(B) m|=SEG_B; if(C) m|=SEG_C; if(D) m|=SEG_D;
  if(E) m|=SEG_E; if(F) m|=SEG_F; if(G) m|=SEG_G;
  return m;
}

const uint8_t BASE_DIGIT[4] = {
  segs(1,0,0,1,1,1),
  segs(1,0,0,1,0,0),
  segs(1,0,0,1,0,0),
  segs(1,1,1,1,0,0) 
};

const uint8_t OFF_DIGIT[12] = { 0,1,2,3,  3,3,  3,2,1,0,  0,0 };
const uint8_t OFF_SEGID[12] = { 'A','A','A','A','B','C','D','D','D','D','F','E' };

static inline uint8_t segMaskFromId(uint8_t id){
  switch(id){
    case 'A': return SEG_A;
    case 'B': return SEG_B;
    case 'C': return SEG_C;
    case 'D': return SEG_D;
    case 'E': return SEG_E;
    case 'F': return SEG_F;
    default:  return 0;
  }
}

void driveAnimationBigRect(){
  static uint8_t phase = 0;
  uint8_t buf[4] = { BASE_DIGIT[0], BASE_DIGIT[1], BASE_DIGIT[2], BASE_DIGIT[3] };
  uint8_t d = OFF_DIGIT[phase];
  uint8_t m = segMaskFromId(OFF_SEGID[phase]);
  buf[d] &= ~m;

  for(uint8_t i=0;i<4;i++) ht_write_digit(i, buf[i], false);
  phase = (phase + 1) % 12;
}

float lastValidM = -1.0f;

void setup(){
#if DEBUG_ULTRA
  Serial.begin(115200); 
  Serial.println(F("Smart Parking Assist (D animation, N dashes, R distance m.xx)"));
#endif
  pinMode(PIN_TRIG, OUTPUT);
  digitalWrite(PIN_TRIG, LOW);
  pinMode(PIN_ECHO, INPUT);
  pinMode(PIN_LIGHT, INPUT);
  pinMode(PIN_D, INPUT);
  pinMode(PIN_N, INPUT);
  pinMode(PIN_R, INPUT);

  Wire.begin();
  ht_init();
  light_ema = analogRead(PIN_LIGHT);
  disp_dashes();
}

void loop(){
  uint16_t adc = analogRead(PIN_LIGHT);
  ht_brightness(light_to_brightness_10step(adc));

  update_gear_latch();

  if (currentGear == GEAR_R) {
    float m = read_distance_m();
    if (m > 0.0f) lastValidM = m;
    if (lastValidM > 0.0f) disp_m2_shifted(lastValidM);
    else disp_dashes();
    delay(3);
  } else if (currentGear == GEAR_D) {
    driveAnimationBigRect();
    delay(120);
  } else {
    disp_dashes();
    delay(60);
  }
}
```

### 스마트 주차 주요 코드 설명
> **#include <Wire.h>**
> - HT16K33과의 I²C 통신을 위한 라이브러리입니다. Wire.begin(), Wire.beginTransmission(), Wire.write(), Wire.endTransmission() 등의 함수가 이 라이브러리에서 제공됩니다.

> **HT16K33_ADDR(0x70)**
> - HT16K33 드라이버의 기본 I²C 주소입니다. 보드에 따라 주소 점퍼 설정으로 달라질 수 있으므로, 동작하지 않으면 주소 확인이 필요합니다. 

> **PIN 정의(PIN_TRIG, PIN_ECHO, PIN_LIGHT, PIN_D/N/R)**
> - 초음파/조도/기어 스위치가 연결된 핀을 상수로 선언합니다. 회로가 변경되어도 핀 번호만 바꾸면 전체 코드가 반영되어 유지보수가 쉬워집니다.

> **digitMap[10]**
> - 0~9 숫자를 7세그먼트에 표시하기 위한 “세그먼트 비트 패턴”입니다.
> - 예를 들어 digitMap[0]은 a,b,c,d,e,f 세그먼트를 켠 상태를 의미합니다.

> **POS_ADDR[4] = {0x00,0x02,0x04,0x06}**
> - HT16K33 내부 메모리에서 각 자리(digit)가 대응되는 주소입니다.
> - 4자리 FND는 각 자리에 대응되는 메모리 위치에 세그먼트 값을 써 주어야 합니다.

> **ht_init()**
> - HT16K33을 초기화합니다.
>   - 0x21 : 오실레이터 ON(칩 동작 시작)
>   - 0x81 : 디스플레이 ON + 블링크 OFF
>   - 0xE0 | 0x0F : 밝기 최대(0~15)
> - 이어서 내부 표시 메모리를 0으로 초기화하여 “잔상/쓰레기 표시”가 없게 합니다. 

> **ht_brightness(lvl)**
> - 밝기를 0~15 범위로 설정합니다.

> **ht_write_digit(idx, seg, dp)**
> - 특정 자리(idx: 0~3)에 세그먼트 패턴(seg)을 쓰고, 필요하면 소수점(dp)을 켭니다.
> - DP_IN_SEGMENT가 true일 때는 소수점이 같은 바이트의 MSB(0x80)에 포함된다는 가정으로 처리합니다.

> **disp_dashes()**
> - ----를 표시하는 함수입니다. 측정 불가/중립 상태에서 사용자가 즉시 상태를 알아볼 수 있도록 “기본 안내 표시” 역할을 합니다.

> **disp_m2_shifted(m)**
> - 거리(m)를 m.xx 형식으로 표시합니다.
> - m*100으로 소수 둘째 자리까지 정수화한 뒤, 정수부(iPart), 소수 첫째(d1), 소수 둘째(d2)를 분리합니다.
> - 표시 레이아웃
>   - 0번 자리: 공백(SEG_BLANK)
>   - 1번 자리: 정수부 + 소수점(dp=true)
>   - 2번 자리: 소수 첫째
>   - 3번 자리: 소수 둘째

> **ultra_trigger() / read_echo_us()**
> - SR04는 TRIG에 약 10µs HIGH 펄스를 주면 측정을 시작합니다. pulseIn(PIN_ECHO, HIGH, 50000UL)는 ECHO가 HIGH로 유지된 시간을 마이크로초 단위로 측정합니다.
> - 세 번째 인자인 50000µs는 “최대 대기 시간(타임아웃)”이며, 이를 초과하면 0이 반환됩니다.

> **read_distance_m()의 60ms 간격 제한**
> - 초음파 센서는 너무 빠르게 연속 측정하면 이전 반사파가 섞여 오차가 커질 수 있습니다. 그래서 마지막 트리거 이후 최소 60ms 간격을 보장하도록 delay를 걸어 안정성을 높입니다. 

> **read_distance_m()의 3회 측정 + 중앙값(median) 선택**
> - 초음파 측정은 환경(각도/재질/잡음)에 따라 순간 튐(outlier)이 생기기 쉽습니다. 3회 측정한 뒤 정렬하여 가운데 값(t[1])을 사용하면, 1번 튄 값이 있어도 결과가 크게 흔들리지 않아 안정적입니다.

> **거리 환산(cm → m)**
> - 음속을 약 343m/s로 보고, 1µs 동안 이동 거리는 약 0.0343cm입니다.

> **LIGHT_ALPHA(EMA 계수)**
> - EMA는 light_ema = (1-α)*이전 + α*현재 형태입니다.
> - α가 크면 반응은 빠르지만 튐에 민감하고, α가 작으면 부드럽지만 반응이 느립니다.

> **pressed_stable()**
> - 스위치 입력은 채터링(짧은 시간 동안 ON/OFF가 튀는 현상)이 발생할 수 있습니다.
> - 눌림(HIGH)을 감지하면 20ms 후 다시 확인하여 여전히 HIGH면 “진짜 눌림”으로 인정합니다.

> **update_gear_latch()**
> - D/N/R 버튼 중 눌린 것을 확인해 currentGear를 갱신합니다. 한 번 선택된 기어는 유지되며, 다른 버튼을 누르면 그 상태로 전환됩니다.

> **driveAnimationBigRect()**
> - 4자리 세그먼트를 `큰 사각형 외곽`처럼 보이도록 기본 패턴(BASE_DIGIT)을 만들어 둡니다. 이후 phase에 따라 특정 자리의 특정 세그먼트(A~F)를 하나씩 꺼서,
>   - “사각형 테두리를 따라 이동하는 꺼짐 점”처럼 보이는 애니메이션을 만듭니다.
> - OFF_DIGIT, OFF_SEGID는 “어느 자리에서 어느 세그먼트를 끌지”를 12단계 시퀀스로 정의한 표라고 보면 됩니다. 

> **lastValidM의 의미**
> - 측정이 실패(us==0)하면 거리값이 -1로 들어올 수 있습니다. 이때 화면이 바로 ----로 바뀌면 사용자 입장에서는 표시가 불안정하게 느껴질 수 있습니다. 그래서 “마지막으로 정상 측정된 값(lastValidM)”을 유지해 표시 안정성을 높였습니다.
